# Website RM Seruit Bunda Fitri
Buka folder ini di VS Code, lalu klik kanan `index.html` > Open with Live Server (ekstensi Live Server), atau buka langsung di browser.
- Ubah menu/harga/paket: `js/menu-data.js`
- Ganti foto: timpa file di `assets/img/` (nama file sama)
- Nomor WhatsApp: variabel `WA` di `js/menu-data.js` dan link `tel:` di `index.html`
- Banner di halaman utama: data di `BANNER` (`js/menu-data.js`), foto `assets/img/banner-1.jpg` dst. Daftar nama foto ada di `assets/img/NAMA-FOTO.txt`
